# Windsurf

Writes [`global_rules.md`](global_rules.md) into `~/.codeium/windsurf/memories/`. Windsurf auto-loads it at session start across every workspace.

The in-app "Manage Memories → Edit global rules" UI edits the same file.

`tok0 init --uninstall` strips tok0 lines and leaves anything else alone.

Docs: <https://docs.windsurf.com/windsurf/cascade/memories>
