# OpenCode (sst/opencode)

Writes [`AGENTS.md`](AGENTS.md) into `~/.config/opencode/`. OpenCode auto-loads it across every session, falling back to `CLAUDE.md` at the same scope if no `AGENTS.md` exists.

`tok0 init --uninstall` strips tok0 lines and leaves anything else alone.

Docs: <https://opencode.ai/docs/rules/>
