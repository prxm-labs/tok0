# Cline

Writes [`tok0.md`](tok0.md) into `~/Documents/Cline/Rules/`.

Cline scans the rules folder but only applies rules you've toggled on. After install, open VS Code → Cline → Rules and flip `tok0.md` on. `tok0 init` prints this reminder.

`tok0 init --uninstall` removes the file. Cline drops the toggle automatically.

Docs: <https://docs.cline.bot/customization/cline-rules>
