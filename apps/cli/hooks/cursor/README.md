# Cursor

Writes [`tok0.md`](tok0.md) into `~/.cursor/`. Cursor doesn't auto-load home-directory markdown. Global User Rules live in the Settings UI; project rules go in `.cursor/rules/*.mdc`.

The file is a reference only. Open Cursor → Settings → Rules → User Rules and paste the contents of `~/.cursor/tok0.md`. `tok0 init` prints this reminder after install.

`tok0 init --uninstall` removes the reference file. The Settings entry is yours to manage.
