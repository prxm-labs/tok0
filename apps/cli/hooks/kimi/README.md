# Kimi Code (Moonshot AI)

Writes [`tok0.md`](tok0.md) into `~/.kimi/`. Kimi has no documented home-directory markdown that it auto-injects; `~/.kimi/config.toml` is for runtime config, not prompt content.

The file is a reference only. Paste it into Kimi's chat-system prompt or its in-app rules editor. `tok0 init` prints this reminder after install.

`tok0 init --uninstall` removes the file.

Docs:
- <https://moonshotai.github.io/kimi-cli/en/configuration/config-files.html>
- <https://moonshotai.github.io/kimi-cli/en/customization/skills.html>
