# Codex

Writes [`AGENTS.md`](AGENTS.md) into `~/.codex/`. Codex auto-loads it.

Codex isn't auto-detected by `tok0 init`. To install, either run `tok0 init --wizard` and pick Codex, or create `~/.codex/` first and re-run `tok0 init`.

`tok0 init --uninstall` strips tok0 lines and leaves anything else alone.
