## [Unreleased]

Targeted for v0.2.0. See [ROADMAP.md](ROADMAP.md) for the full plan.

### Added
- `tok0 doctor` — diagnostic health checks for config dir writability,
  DB path, hook freshness per detected tool, extension rule validity,
  and project-trust vs rule presence. Exits 1 on any Error.
- `tok0 rule list|show|test` — rule management CLI.
  - `list` enumerates builtin + extension + project-local rules with
    provenance labels and a formatted table.
  - `show <name>` prints the full FilterConfig (commands, strip patterns,
    head/tail lines, empty message).
  - `test <name>` reads stdin, applies the rule, prints before/after +
    savings %.
- Shell completion hint: `tok0 init` now detects `$SHELL` and prints the
  exact `tok0 completions <shell> > <path>` command for the user's shell.
- `tok0 init --uninstall` + `--wizard` for guided onboarding and clean
  removal.
- `OpenCode` added as a supported AI tool (`~/.config/opencode/AGENTS.md`).
- Per-tool post-install hints replacing the narrower "GUI-only" check:
  Cursor + Kimi Code tell users to paste into Settings, Cline points
  users at the Rules panel toggle.

### Changed
- **Breaking**: tool installers now write to canonical 2026 config paths.
  Previous v0.1.0 installs placed files where the target tools did not
  actually read them.
  - Windsurf → `~/.codeium/windsurf/memories/global_rules.md`
  - Cline → `~/Documents/Cline/Rules/tok0.md` (toggle on in panel)
  - Amp → `~/.config/amp/AGENTS.md`
  - OpenCode → `~/.config/opencode/AGENTS.md`
  - Cursor + Kimi Code unchanged (GUI-only reference files).
- Detection logic updated: Windsurf detects both `~/.codeium/windsurf`
  and legacy `~/.windsurf`; Cline detects via `~/Documents/Cline`;
  Amp and OpenCode detect via `~/.config/<tool>` or binary in `PATH`.
- Metering is now fully async via an mpsc `sync_channel` + background
  `tok0-meter` worker thread; `record()` returns in microseconds.
  `flush()` with a 500ms watchdog drains the worker before exit.
- API credentials stored in the `CloudConfig` struct are zeroized on drop.
- "Untrusted project rules skipped" stderr hint now prints at most once
  per process via `OnceLock`.

### Fixed
- Homebrew formula SHA-256 placeholders replaced with real checksums
  via `scripts/update-formula.sh`.
- Install scripts (`install.sh`, `install.ps1`, `scripts/update-formula.sh`,
  `Formula/tok0.rb`) now all reference `prxm-labs/tok0` instead of the
  wrong `tok0/tok0` placeholder.
- Release workflow renames each matrix binary with its target triple
  (`tok0-<target>`) so macOS-x86_64, macOS-aarch64, and Linux-musl
  artifacts no longer clobber each other in the release.
- Clippy cleanups for Rust 1.95 stable: `manual_checked_ops`,
  `unnecessary_sort_by`, `nonminimal_bool`.

### Security
- Trust gating enforced: `.tok0/filters/*.toml` only loads when the
  project has been explicitly trusted via `tok0 trust`.
- Extension name validation blocks path-traversal in
  `tok0 ext install <url>`.

### Tests
- 1611 total tests passing across lib, bin, and CLI integration suites.
- New property tests (proptest) for `bridge::rewriter` and
  `bridge::adapters`.
- End-to-end CLI integration tests spawning the release binary against
  isolated `TOK0_DB_PATH` temp dirs.
- `scripts/test-install-sh.sh` smoke test for `install.sh` against a
  local HTTP server.

## [0.1.0] — 2026-04-22

Initial release.

### Added
- Core 8-stage compression pipeline (strip ANSI → pattern replace →
  output match → line select → truncate lines → head/tail → hard cap
  → empty message).
- Native compressors for 30+ commands across git, cargo, npm, docker,
  kubectl, terraform, pytest, and system utilities.
- 58 built-in TOML compression rules embedded at compile time.
- 12 catch-all rules for cargo / npm / docker / kubectl / go / pip / gh
  / brew / terraform / dotnet / redis / apt, covering unknown
  subcommands that previously got 0% compression.
- Metering database (SQLite, WAL mode) with threshold-based rollup:
  days with >100 rows get aggregated into `commands_rollup` and the
  detail rows deleted.
- `tok0 init` hook installer with detection of 7 AI tools.
- `tok0 status`, `tok0 stats`, `tok0 telemetry`, `tok0 discover`,
  `tok0 proxy`, `tok0 completions`, `tok0 trust`/`untrust`,
  `tok0 verify`, `tok0 ext install/list/remove`.
- Multi-platform release binaries: `x86_64-apple-darwin`,
  `aarch64-apple-darwin`, `x86_64-unknown-linux-musl`,
  `x86_64-pc-windows-msvc`.
- SHA-256 verification in both `install.sh` and `install.ps1`.
- Homebrew formula at `Formula/tok0.rb`.
